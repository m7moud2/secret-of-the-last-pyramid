# سر الهرم الأخير — Secret of the Last Pyramid 🏺⚔️

لعبة أكشن وتقمص أدوار (Action RPG) مبنية بتقنيات الويب الحديثة (HTML5 Canvas + Tailwind CSS + Web Audio API)، مستوحاة من أسرار الفراعنة والأهرامات المصرية القديمة.

---

## 🎮 نبذة عن اللعبة
تقمص دور عالم الآثار والمستكشف **آدم** الذي يدخل الهرم الأخير بحثاً عن **جوهرة الحياة الأسطورية**. عليك مواجهة الوحوش والحراس القدماء، تفادي الفخاخ القاتلة، جمع الذهب وأحجار الشمس، وتطوير أسلحتك لخوض المعركة الحاسمة ضد كاهن المعبد.

---

## ⚔️ مميزات اللعبة

* **أعداء متنوعون بذكاء اصطناعي تفاعلي:**
  * 🦂 **عقرب الصحراء:** لدغات سريعة وسامة.
  * 🐍 **الكوبرا الملكية:** هجمات سم بعيدة المدى.
  * 🧟 **المومياء الحارسة:** قوة تحمل هائلة مع قدرة فريدة على النهوض مجدداً بعد الموت.
  * 👤 **جندي الظل:** سرعة خاطفة وهجمات مباغتة.
  * 👑 **حارس المعبد الحجري (الزعيم):** ضربات زلزالية وموجات صدمية متفجرة.

* **ترسانة أسلحة قابلة للتطوير (+1 إلى +20):**
  * 🗡️ **خنجر الرمال** (سرعة فائقة وضربات حرجة)
  * ⚔️ **سيف الفرعون** (هجوم دائري متوازن)
  * 🔱 **رمح رع المقدس** (مدى طويل واختراق)
  * 🏹 **قوس أوزوريس** (إطلاق 3 سهام طاقة متزامنة)
  * ⚡ **شفرة أنوبيس** (سلاح أسطوري مقدس)

* **نظام تطوير وترقية فرعوني كامل:**
  * تطوير القوة والضربات الحرجة باستخدام الذهب 🪙 وأحجار الشمس ☀️.
  * حساب احتمالات النجاح والفشل ونظام الندرة (عادي، نادر، ملحمي، أسطوري، مقدس).

* **تحكم مزدوج كامل (Desktop & Mobile):**
  * 📱 **الهواتف:** عصا تحكم افتراضية سلسة (Virtual Joystick) + أزرار لمس سريعة.
  * 💻 **الحواسيب:** دعم لوحة المفاتيح والماوس (`WASD`، `Space`، `K`، `L`).

* **محرك صوتي إجرائي مدمج (Web Audio Synthesizer):**
  * مؤثرات صوتية فورية خفيفة دون الحاجة لتحميل ملفات صوتية خارجية.

## 🕹️ أدوات التحكم

### على أجهزة الكمبيوتر:
| الوظيفة | الزر |
| :--- | :--- |
| **الحركة** | `W` `A` `S` `D` أو مفاتيح الأسهم |
| **الهجوم** | زر الماوس الأيسر أو `Space` / `J` |
| **المهارة الخارقة (شعاع رع)** | زر الماوس الأيمن أو `K` |
| **المراوغة السريعة (Dash)** | `L` أو `Shift` |
| **إيقاف مؤقت** | `P` أو `Esc` |

### على الهواتف والأجهزة اللوحية:
* **عصا التحكم (اليسار):** توجيه حركة المستكشف 360 درجة.
* **الأزرار (اليمين):** ⚔️ هجوم، 🔥 مهارة شعاع رع، 💨 مراوغة، ❤️ جرعة شفاء.
